# The World's Fastest Markdown Introduction

Markdown (`.md`) is an incredibly lightweight markup language that lets you format plain-text documents using simple symbols rather than complicated formatting tools. For example, you create headings with `#`, bulleted lists with `-`, and hyperlinks with `[link text](URL)`. We use markdown because it is easy to read, write, version control with Git, and render into formatted documents such as HTML, PDF, or even Word. As data scientists, you will find markdown commonly used for project `README`s, documentation, and reproducible workflows. So, developing this skill now will make it much easier to effectively communicate your work!

Let's speak in markdown:

---

# This is my First-Level Heading
## This is my Second-Level Heading
### This is my Third-Level
#### ... Fourth-Level ...
##### ... Fifth-Level ...

---

I made a line! These can be nice to separate sections.

---

_This is in italics._ *This is also in italics!*

__This is in bold.__ **This is also in bold!**

* I like to make bulleted lists.
* And another bullet...
	* And an indented bullet

- But then I can make lists like this too
  - and indent them again

1. I like to make numbered lists as well.
2. Second item.
3. Now I have too many items.

I like to embed some links like [the Merrimack homepage](https://www.merrimack.edu)

Now I will make a table (__read me left to right, top to bottom__):

| Stuff | In | My | Table |
| ---- | ---- | ----- | -----|
| There | are | a lot | of things|
| I can | do to | format tables | but |
| I will | keep it | simple | here! |

---
