# README

## Dataset description
This dataset contains images of healthy and diseased leaves from multiple crop species, assembled to support research on automated plant disease diagnosis. The PlantVillage collection contains approximately 54,000 images across 14 crop species and 26 diseases. Primary uses could include:

- classifying crop leaves by disease category
- comparing traditional image features with transfer learning approaches
- evaluating performance across imbalanced disease classes
- examining how controlled image backgrounds may limit generalization to field conditions

### Possible question

How do controlled image backgrounds limit generalization to field conditions in automated plant disease diagnosis?

## Source Citation
Mohanty, Sharada P.; Hughes, David P.; Salathé, Marcel (2016). Using deep learning for image-based plant disease detection. *Frontiers in Plant Science*, 7, 1419. https://doi.org/10.3389/fpls.2016.01419

Dataset repository: PlantVillage-Dataset. https://github.com/spMohanty/PlantVillage-Dataset

## Data documentation
The repository `README` describes the image collection, class labels, available image variants, and citation. The dataset can be accessed through the repository or its linked Hugging Face dataset page: https://huggingface.co/datasets/mohanty/PlantVillage

## Additional notes
The repository provides class labels through folder/class names rather than a conventional tabular codebook. Verify the terms applicable to the exact image distribution you select; the GitHub repository itself does not clearly display a standalone license file.
