# README

## Dataset description
This dataset contains soccer match event data released by StatsBomb for research and football (soccer) analytics. It includes competition and season metadata, match information, event records, lineups, and 360-degree contextual data for selected matches. Primary uses could include:

- modeling shot outcomes and estimating expected goals from shot context
- identifying possession sequences associated with dangerous scoring opportunities
- comparing event and passing patterns across teams or competitions
- building spatial features and evaluating how attacking patterns relate to outcomes

## Source Citation
StatsBomb. StatsBomb Open Data. GitHub repository. https://github.com/hudl/open-data

## Data documentation
The repository `README` describes the folder structure and file organization. Definitions and details of event fields and JSON structure are provided in the repository's `doc` directory: https://github.com/hudl/open-data/tree/master/doc

If publishing, sharing, or distributing research based on these data, follow StatsBomb's stated attribution requirements and identify StatsBomb as the data source.

# Additional notes
Data are `JSON` rather than a ready-made rectangular table. Select a manageable competition/season or match set, and __follow the repository's attribution terms__. Failure to do this means I will not allow you to use these data for your project.
