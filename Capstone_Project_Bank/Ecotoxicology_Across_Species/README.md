# README

## Dataset description
This research dataset, released in September 2026, contains curated experimental ecotoxicity data compiled from multiple sources. It was developed to support species sensitivity distributions (SSDs) and ecological risk assessment. The downloadable Excel file is approximately 42 MB.

Possible analytical directions include:
- Modeling toxicity using chemical characteristics, species groups, and test conditions
- Comparing results across taxonomic groups and evaluating uncertainty in the available evidence
- Comparing toxicity endpoints across species and chemical groups

## Data documentation
The dataset is organized into member information, subscription transactions, daily listening logs, and churn labels. A useful overview of the tables and their relationships is available in Databricks' instructional walkthrough: https://www.databricks.com/notebooks/churn/1-data-preparation.html
