# README

## Dataset description
Mobile Health (mHealth) symptom-based health checkers are a rapidly evolving area with significant implications for healthcare. Accurate and efficient tools that can differentiate diagnoses can enhance patient outcomes and optimize healthcare resources. These data were generated from a simulated mHealth application to track symptoms for 10 diseases using over 9,000 patient samples. These data were developed using clinical vignettes to gauge the real-world applicability of the symptoms in the questionnaire. These data could be used to judge the performance of the mHealth tracker when combined with machine learning models to provide an **accurate, differentiated diagnosis** to patients from among these 10 diseases based only on their symptoms in the questionnaire. 

### The 10 diseases in the dataset are:
- Influenza
- Pneumonia
- Common cold
- Acute sinusitis
- Chronic sinusitis
- Asthma
- Pertussis
- Acute bronchitis
- Bronchiolitis
- Gastroesophageal reflux disease (GERD)

### Possible question
How effectively can machine learning differentiate diagnosis of common diseases with overlapping symptomatology as recorded by a mobile health (mHealth) questionnaire?
