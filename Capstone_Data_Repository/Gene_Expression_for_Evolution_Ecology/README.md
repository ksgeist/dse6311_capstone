Your job would be to take on one piece of the bigger research project during your Capstone. Currently, this research opportunity is only open to students who have take DSE6630. 

## Project description
This project investigates machine-learning methods for analyzing gene expression data in eco-evolutionary and environmental research. Students will contribute to an ongoing methods-focused research effort by analyzing new datasets with established methods or reanalyzing previously studied datasets with alternative methods. The goal is to demonstrate how methodological choices affect analysis and interpretation of gene expression patterns in biological research. Primary uses could include:

- applying established machine-learning methods to a new gene expression dataset
- comparing alternative preprocessing, feature selection, and modeling strategies
- reanalyzing previously studied datasets using novel methods
- evaluating model performance and the consistency of results across datasets
- contributing reproducible analyses toward a methods overview publication

## Project pathways
**Pathway 1**: New dataset using established methods

Select a new dataset, with instructor guidance, and apply methods used from our existing research framework. Starter code and previous analyses would be provided to support consistency across studies.

**Pathway 2**: New methods using existing datasets

Use one dataset that has already been analyzed __by researchers but not using machine learning methods__. You will investigate alternative or novel methods using machine learning. The emphasis is on methodological comparison and reproducible evaluation rather than repeating the original analysis.

## Data source
The specific dataset or datasets will be selected with the instructor based on the research question, data availability, and project scope. Existing datasets, preprocessing, and code may be supplied for the selected pathway. For this reason, you should reach out to Dr. Geist immediately if you're interested in this project, with your chosen pathway.

## Expectations
- Establish a clearly defined analytical question and document the biological context
- Follow a consistent analysis framework when comparing datasets or methods
- Evaluate preprocessing, feature selection, and model choices using an appropriate validation strategy
- Interpret findings in the context of the biological study rather than treating model performance as the sole outcome
- Provide reproducible code and documentation that can be incorporated into the ongoing research effort

## Source citation
Dataset-specific citations will be provided once the project dataset or datasets have been selected. Students should cite the original research and data sources for every dataset used, along with any methods or software that materially contribute to the analysis.
