# README

## Dataset description
This dataset contains bus GPS traces and processed transit records for three bus routes in Astana, Kazakhstan. It includes trip-l and stop-level timing information and segment travel times, supporting analysis of bus travel- ime prediction and service reliability. Primary uses could include:

- predicting travel times between consecutive stops
- identifying route segments and times of day associated with greater travel-time variability
- examining the relative contribution of stop dwell time and between-stop travel time
- developing a reliability dashboard to communicate typical travel times and uncertainty

### Possible question
Can we predict bus travel times and identify when and where transit service becomes unreliable?
